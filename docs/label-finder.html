Step 0 · optional

Label finder (YOLO label detection and cropping)

Finds labels in a photo and saves each one as its own picture. It can find anything that looks reasonably consistent, such as pages of a book, signs, forms or plant tags.

What it does

You show the tool what to look for by drawing boxes around the labels on a handful of photos. It learns from those examples (annotation, then training a YOLO model) and then finds the labels in all your other photos (prediction) and cuts them out (cropping). Each cut-out is saved as <specimen>_label_01.png, <specimen>_label_02.png and so on.

You may not need this tool

If you already have one picture per label, or you are working from notebook pages or ledger scans, skip it and go to the label reader.

It is free to use. It runs on your computer and your pictures are never sent anywhere. The tool only copies your pictures. Your originals are never changed.

What you need

  • A Mac or a Windows computer.
  • Python 3.10 or newer (the programming language the tool is written in). You install it once, like any other program.
  • About 2 GB of free space and a good internet connection for the first install.
  • A folder of photos. Around 20 to 50 is a reasonable start for teaching it.

Install, once

  1. Install Python

    Download it from python.org/downloads and run the installer.

    • Windows: on the first screen of the installer, tick Add Python to PATH. This matters.
    • Mac: click through the installer.

  2. Download editha

    Download the ZIP file. Unzip it somewhere you will find again, like your Desktop or Documents. Open the folder label-finder-cropper-yolo.

  3. Double-click the installer

    Mac: Install editha label finder.command
    Windows: Install editha label finder.bat

    A black window opens and sets everything up inside the app folder. It downloads about 2 GB and takes several minutes. When it says Installation complete, close the window.

Your Mac may block the file the first time

You will probably see a message such as Apple could not verify…. This is expected, because the file is not signed with an Apple developer certificate. To allow it:

  1. Double-click the file once and dismiss the message.
  2. Open System Settings (called System Preferences on older Macs) and go to Privacy & Security.
  3. Scroll down to Security. You will see that the file was blocked. Click Open Anyway and enter your password.
  4. Double-click the file again and click Open.

You do this once for each of the two .command files (install and start).

Windows may show a blue warning

If it says Windows protected your PC, click More info, then Run anyway.

Use it

To start the tool, double-click Start editha label finder.command (Mac) or Start editha label finder.bat (Windows). It opens in your web browser. A black window stays open behind it. Leave that window open while you work. Closing it stops the tool. When you are finished, close the browser tab and then the black window.

Do this first

Create a project

On the front page, type a name and press Create. Everything you do is filed under that project, so separate projects never overwrite each other. Use underscores instead of spaces.

The name shown at the top of each page is the project your work goes into. If you forget to choose one, the work is filed under a folder literally called No project selected.

Then work through the five pages in the left-hand sidebar, in order. Let each one finish before you start the next.

  1. Upload images (bring in a training set)

    Choose the folder with your photos, either by typing its location or with the Browse… button. Pick how many to bring in. That many are chosen at random and copied into the project. About 20 to 50 is a good start. Use more if the labels vary a lot or are complicated. About 20% are held back automatically so the tool can test itself (validation set).

  2. Annotate images (draw boxes)

    Draw a box around every label you want found, on each photo.

    • Draw: click and drag on an empty part of the image.
    • Move or resize: click a box, then drag it or its corner handles.
    • Delete: switch Mode (right of the image) from Transform to Del, click the box, then switch back.
    • Click Complete to save each image. The status line turns green.
    • If an image has no labels, click Complete without drawing, or use Nothing to find here. These photos teach the tool what to ignore.

    Your boxes are saved as you go, so you can close the tool and come back. When every image is done, click Build training set. Then open Check your boxes and page through a few images. Every red box should sit around a label. If you change any boxes afterwards, click Build training set again, otherwise the next step learns from the old boxes.

  3. Train model (let it learn)

    Choose the number of training rounds (epochs). We recommend at least 50. More rounds give better results and take longer. Click Start training.

    Training can take minutes to hours, depending on your computer and how many images you used. Wait until it reports success. If it fails, a log is written to runs/train_log.txt inside your project folder, and it usually says why.

  4. Predict (preview what it finds)

    Run the trained model over a folder of photos and look at the previews, with boxes drawn on. Open a few and check they look right before you cut anything out.

  5. Crop images (cut the labels out)

    Saves one picture per label found. You can set:

    • How many images to do. 0 means all of them.
    • Extra space around each cut-out, in pixels (10 by default).
    • Minimum confidence. Only labels the tool is at least this sure about are cut out. The default is 0.90. Lower it if too few labels come through.
Starting fresh

To try a different set of photos, create a new project on the front page. The old project's results stay where they are. To redo a project in place instead, delete its data and runs folders.

Where your files go

Everything lives inside the app folder, under projects/<your project>/:

FolderWhat is in it
data/01_train_val_subsetThe photos brought in at step 1
data/annotations.jsonThe boxes you drew at step 2
data/02_yolo_datasetThe training set built at step 2
data/03_prediction_previewPreviews from step 4
data/04_cropping_resultThe cut-out labels from step 5. This is the folder you take to the label reader.

If something goes wrong

The Mac says it cannot open the file

Follow the Open Anyway steps under Install above. If it says permission denied instead, open Terminal, type chmod +x followed by a space, drag the file onto the Terminal window and press Enter.

The installer says Python was not found

Install Python from python.org/downloads, then double-click the installer again. On Windows, make sure you ticked Add Python to PATH. If you did not, run the Python installer again and choose Modify.

The install stopped or failed

Check your internet connection and double-click the installer again. It carries on where it left off.

The page will not open, or stopped working

Make sure the black window is still open. Closing it stops the tool. Close the tab, close the black window, and start again with the Start file.

A step says the one before it is not finished

Go back one page and finish it. Training needs a built training set, and predicting or cropping needs a trained model.

It misses labels, or finds things that are not labels

Add more example photos at step 1, especially ones where it went wrong. Draw boxes on them, build the training set again and train again. For missed labels you can also lower the minimum confidence when cropping.

I want to update to a newer version

Download the ZIP again and copy your projects folder into the new app folder. Your work is stored in projects.
